# 이음 IEUM

**이음은 장애인 당사자와 보호자·가족을 위한 정보 커뮤니티입니다.** 생활, 의료·복지, 취업 정보를 쉽게 찾고 서로의 경험과 질문을 나눌 수 있도록 기획했습니다.

웹 퍼블리싱 역량과 사용자 중심의 정보 구조 설계를 보여주기 위해 제작한 비상업적 포트폴리오입니다.

## 주요 사용자

- 장애인 당사자
- 보호자와 가족
- 생활·복지·의료·취업 정보를 찾는 사용자

## 주요 기능

- 최신 사업 공지와 생활 정보 제공
- 인기 게시글과 추천 기관 안내
- 콘텐츠 주제에 맞는 페이지 연결
- API 없이 작동하는 선택형 안내 도우미
- 생활정보, 의료·도움, 취업서비스, 정보공유를 고를 수 있는 탭형 선택 버튼
- PC, 태블릿, 모바일 반응형 화면

## 접근성 고려

- 본문 바로가기 링크 제공
- 의미 있는 `<a>` 링크 사용
- 키보드 포커스 표시
- 이미지 대체 텍스트 작성
- 메뉴와 안내 도우미에 ARIA 속성 적용
- 색상과 밑줄을 함께 사용해 링크 상태 표현
- 작은 글자를 직접 입력하는 방식 대신 크고 명확한 탭형 버튼을 사용해 원하는 정보에 쉽게 접근하도록 구성
- 버튼의 글자와 배경 대비, 충분한 클릭 영역, 키보드 선택을 고려

## 디자인 시스템

KRDS(대한민국 디지털 정부서비스 UI/UX 가이드라인)를 공부하며 정보 구조, 버튼, 입력 요소와 접근성 기준을 참고했습니다. 색상만으로 정보를 구분하지 않고, 색각 다양성을 고려해 서로 구분하기 쉬운 대비와 색상 조합을 선택했습니다.

공통 색상과 글자 크기는 `vars.css`, 초기화와 공통 규칙은 `common.css`, 일반 화면은 `style.css`, 반응형 화면은 `media.css`로 역할을 나누어 관리했습니다.

## AI 활용 범위

생성형 AI는 프로젝트 기획 내용 정리, 예시 문구 작성, 코드 검토, 반응형 화면과 웹 접근성 개선 사항을 확인하는 보조 도구로 활용했습니다. 서비스의 대상과 정보 구조, 디자인 방향, 최종 코드 선택과 수정은 직접 진행했습니다.

사이트의 `이음 도우미`는 실제 AI 챗봇이 아니라 사용자가 탭형 버튼으로 관심 분야를 선택하면 미리 작성된 설명과 페이지 링크를 제공하는 규칙 기반 안내 기능입니다. 자유 입력이 어려운 사용자도 원하는 정보로 이동할 수 있도록 선택 과정을 단순하게 구성했습니다.

## 사용 기술

- HTML5
- CSS3
- JavaScript
- CSS 변수
- 반응형 웹

## 현재 구현 범위

현재 저장소에는 메인페이지와 생활정보 화면을 중심으로 정적 UI가 구현되어 있습니다. 의료·도움, 취업서비스, 정보공유, 마이페이지, 글쓰기, 개인정보처리방침은 전체 서비스 구성을 보여주기 위해 기획했으며 일부 페이지는 추가 구현이 필요합니다.

## 안내 사항

- 화면의 기관, 사업, 채용, 게시글은 포트폴리오용 가상 콘텐츠입니다.
- 실제 API, 데이터베이스, 회원 인증 기능은 연결되어 있지 않습니다.
- 안내 도우미는 실제 AI가 아닌 선택형 안내 기능입니다.
- 개인정보를 입력하거나 저장하지 않습니다.
- 실제 의료·복지 정보를 이용하기 전에는 공식 기관의 최신 정보를 확인해야 합니다.
